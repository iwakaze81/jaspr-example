Flutter はモバイルでネイティブ ARM コードに、Web では WebAssembly にコンパイルされます。ブリッジなし。ラッパーなし。

🌐

Web

Jaspr + Flutter Web で構築。SEO 対応 LP に Flutter ウィジェットを埋め込み。

  • ✓ Progressive Web App
  • ✓ WebAssembly ターゲット
  • ✓ JS フレームワーク不要
📱

iOS

ネイティブ ARM64 にコンパイル。Flutter プラグイン経由でプラットフォーム API に直アクセス。

  • ✓ ネイティブパフォーマンス
  • ✓ プラットフォーム外観
  • ✓ App Store 対応
🤖

Android

ネイティブ ARM64/x86 にコンパイル。Flutter のレンダリングエンジンで Material Design を実現。

  • ✓ Google Play 対応
  • ✓ アダプティブアイコン
  • ✓ Material You 対応
